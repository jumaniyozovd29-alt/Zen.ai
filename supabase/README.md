# Supabase ulash

1. Supabase’da yangi project yarating.
2. SQL Editor’da `supabase/schema.sql` faylini to‘liq ishga tushiring.
3. Project Settings → API’dan Project URL, anon public key va service_role key oling.
4. Kalitlarni faqat backend environment variables ichida saqlang.
5. GitHub’ga haqiqiy kalitlarni yubormang.

SQL sxema tayyor, lekin Supabase project hali real ulanmagan.
