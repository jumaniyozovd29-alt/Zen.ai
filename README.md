- Boshlang‘ich frontend prototipi: keyingi commitda qo‘shiladi
- Backend: ulanmagan
- Autentifikatsiya: ulanmagan
- Ma’lumotlar bazasi va limit hisoblagichi: ulanmagan
- AI provayder API: ulanmagan
- To‘lovlar: ulanmagan
- Hosting va domen: ulanmagan
